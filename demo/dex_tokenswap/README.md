# DexTokenSwap — Real-World DEX Demo

A constant-product AMM (x·y = k) DEX that demonstrates end-to-end XTract
transpilation: from production-quality Solidity to a deployable MultiversX
smart contract in seconds.

## What the contract does

| Endpoint | Description |
|---|---|
| `deposit(token, amount)` | Add liquidity for a token |
| `withdraw(token, amount)` | Remove deposited liquidity |
| `swap(tokenIn, amountIn, tokenOut)` | AMM swap: `amountOut = amountIn·reserveOut / (reserveIn + amountIn)` |
| `getPrice(tokenIn, tokenOut)` | Spot price scaled by 1e18 |
| `getReserve(token)` | Raw reserve balance for a token |

### Solidity patterns → MultiversX output

| Solidity pattern | XTract output |
|---|---|
| `bool public locked` | `#[storage_mapper("locked")] fn locked() -> SingleValueMapper<bool>` |
| `mapping(address => uint256) public reserves` | `#[storage_mapper("reserves")] fn reserves(&self, key: &ManagedAddress) -> SingleValueMapper<BigUint>` |
| `mapping(address => mapping(address => uint256)) public balances` | Two-key `SingleValueMapper` with `key1`, `key2` parameters |
| `modifier nonReentrant()` | Expanded inline: `require!(!self.locked().get(), …)` |
| `modifier onlyOwner()` | `require!(self.blockchain().get_caller() == …)` |
| `uint256 amountOut = expr` | `let mut amount_out: BigUint<Self::Api> = expr` *(A1)* |
| `reserves` detected without whitelist | Dynamic storage detection *(A2)* |
| `event Swap(address indexed, …)` | `#[event("Swap")] fn swap_event(&self, #[indexed] …)` |
| `require(cond, "msg")` | `require!(cond, "msg")` |

### What xtract handles automatically

- **All 4 storage variables** (`owner`, `locked`, `reserves`, `balances`) detected and
  emitted as `#[storage_mapper]` without any manual configuration
- **Events** with correct `#[indexed]` attributes
- **Modifier inlining** — `nonReentrant` and `onlyOwner` expanded into endpoint bodies
- **Type mapping** — `uint256` → `BigUint<Self::Api>`, `address` → `ManagedAddress<Self::Api>`, `bool` → `bool`
- **View vs endpoint** — `public view` → `#[view]`, `public` → `#[endpoint]`
- **Local variable declarations** — `uint256 x = expr` → `let mut x: BigUint<Self::Api> = expr` *(A1)*

## Transpile

```bash
# From the repo root
xtract demo/dex_tokenswap/src/DexTokenSwap.sol \
        demo/dex_tokenswap/src/DexTokenSwap.rs
```

Or programmatically via the Node.js SDK:

```ts
import { XtractTranspiler } from '@xtract/sdk';
const result = await new XtractTranspiler().transpileFile('./src/DexTokenSwap.sol');
```

---

## Build

Install the MultiversX Rust toolchain once:

```bash
rustup target add wasm32-unknown-unknown
cargo install multiversx-sc-meta
```

Then from this directory:

```bash
sc-meta all build
```

Produces `output/dex-token-swap.wasm` (~4 KB).

---

## Deploy

```bash
export WALLET_PEM=./wallet.pem
npx ts-node deploy.ts
```

The deploy script re-transpiles, builds (requires `sc-meta` on `PATH`), and
deploys to devnet, printing the contract address and tx hash. Change
`Networks.devnet()` to `Networks.mainnet()` for production.
