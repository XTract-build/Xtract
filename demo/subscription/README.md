# Subscription — Real-World SaaS Demo

A recurring-payment / subscription contract that demonstrates XTract's handling
of Solidity structs, `mapping(address => StructArray)`, timestamp arithmetic,
and payable endpoints — all transpiled to deployable MultiversX Rust.

## What the contract does

| Endpoint | Description |
|---|---|
| `registerService(service)` | Register as a service provider (caller becomes service owner) |
| `addPlan(service, price, duration)` | Add a subscription tier (price in wei, duration in seconds) |
| `deactivatePlan(service, planId)` | Disable a plan so no new subs can be created |
| `subscribe(service, planId)` | Pay and subscribe; `expiresAt = now + plan.duration` |
| `renew(service)` | Extend before or after expiry (no gap in coverage if renewed early) |
| `cancel(service)` | Cancel immediately — no refund |
| `isActive(user, service)` | Time-based view: `!cancelled && expiresAt > now` |
| `planCount(service)` | Number of plans registered for a service |
| `withdraw(service)` | Service owner claims accumulated payments |

### Solidity patterns → MultiversX output

| Solidity pattern | XTract output |
|---|---|
| `struct Plan { uint256 price; … }` | `#[derive(TopEncode, TopDecode, …)] pub struct Plan<M: ManagedTypeApi>` |
| `struct SubscriptionRecord { … }` | `#[derive(TopEncode, TopDecode, …)] pub struct SubscriptionRecord` |
| `mapping(address => Plan[])` | `#[storage_mapper] fn service_plans(&self, service: &ManagedAddress) -> VecMapper<Plan<Self::Api>>` |
| `mapping(address => mapping(address => SubscriptionRecord))` | Two-key `SingleValueMapper<SubscriptionRecord>` |
| `mapping(address => uint256) serviceBalance` | `#[storage_mapper] fn service_balance(&self, key: &ManagedAddress) -> SingleValueMapper<BigUint<Self::Api>>` |
| `modifier onlyServiceOwner(address service)` | Inlined `require!(caller == self.service_owner(&service).get(), …)` |
| `function subscribe(…) public payable` | `#[payable("EGLD")] #[endpoint] fn subscribe(…)` |
| `msg.value` | `self.call_value().egld_value().clone_value()` |
| `block.timestamp` | `self.blockchain().get_block_timestamp()` |
| `servicePlans[service][planId]` | `self.service_plans(&service).get((plan_id + 1) as usize)` *(VecMapper is 1-indexed)* |
| `servicePlans[service].push(…)` | `self.service_plans(&service).push(&plan)` |
| `servicePlans[service].length` | `self.service_plans(&service).len()` |

### What xtract handles automatically

- **5 storage variables** auto-detected and emitted as `#[storage_mapper]`
- **Struct encoding** — derives `TopEncode`, `TopDecode`, `NestedEncode`, `NestedDecode`, `TypeAbi`
- **Events** with correct `#[indexed]` attributes
- **Modifier inlining** — `onlyOwner` and `onlyServiceOwner` expanded into endpoints
- **Type mapping** — `uint256` → `BigUint<Self::Api>`, `address` → `ManagedAddress<Self::Api>`,
  timestamp fields → `u64`
- **payable functions** — `#[payable("EGLD")]` annotation + `call_value().egld_value()`
- **View vs endpoint** — `public view` → `#[view(…)]`, `public` → `#[endpoint]`

## Transpile

```bash
# From the repo root
xtract demo/subscription/src/Subscription.sol \
        demo/subscription/src/Subscription.rs
```

Or programmatically via the Node.js SDK:

```ts
import { XtractTranspiler } from '@xtract/sdk';
const result = await new XtractTranspiler().transpileFile('./src/Subscription.sol');
```

---

## Build

Install the MultiversX Rust toolchain once:

```bash
rustup target add wasm32-unknown-unknown
cargo install multiversx-sc-meta
```

Then from this directory:

```bash
sc-meta all build
```

Produces `output/subscription.wasm`.

---

## Deploy

```bash
export WALLET_PEM=./wallet.pem
npx ts-node deploy.ts
```

The deploy script re-transpiles, builds, and deploys to devnet, printing the
contract address and tx hash.  Change `Networks.devnet()` to `Networks.mainnet()`
for production.
