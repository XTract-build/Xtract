# DaoGovernance — DAO Governance Demo

An on-chain proposal voting system that demonstrates real-world
Solidity→MultiversX Rust transpilation with XTract, focusing on
nested mappings, struct field updates (A5), and modifier-based access control.

## What the contract does

| Endpoint | Description |
|---|---|
| `createProposal(description)` | Create a new governance proposal. Returns the proposal ID. |
| `vote(proposalId, support)` | Cast a for/against vote. One vote per address per proposal. |
| `execute(proposalId)` | Execute an approved proposal after its deadline (quorum required). |
| `getVoteCount(id)` | View — returns the for-vote count of a proposal. |
| `getDeadline(id)` | View — returns the voting deadline timestamp. |
| `didVote(proposalId, voter)` | View — returns whether an address voted on a proposal. |
| `setQuorum(newQuorum)` | Owner-only — update the minimum votes required to execute. |

### Solidity patterns exercised

- **A5 struct-field-update** — `proposals[id].executed = true` → load-mutate-store:
  ```rust
  let mut s = self.proposals(&id).get();
  s.executed = true;
  self.proposals(&id).set(&s);
  ```
- **A2 nested-mapping dynamic detection** — `mapping(uint256 => mapping(address => bool)) hasVoted`
  detected at transpile time → `fn has_voted(&self, key1: &BigUint, key2: &ManagedAddress) -> SingleValueMapper<bool>`
- **onlyAfterDeadline modifier** — checks `proposals[proposalId].deadline` via A5 struct read
- **block.timestamp comparisons** — deadline enforcement in `vote()` and `execute()`
- **Events** — `ProposalCreated`, `VoteCast`, `ProposalExecuted` with indexed params

### Transpiler notes

| Pattern | Behaviour |
|---|---|
| `proposals[id].voteCount = proposals[id].voteCount + 1` | A5 load-mutate-store ✓ |
| `hasVoted[proposalId][msg.sender] = true` | Two-key nested write; add `self.has_voted(&id, &caller).set(true)` manually after transpile |
| Control-flow ordering | `if/else` blocks are extracted before linear statements; reorder `require!` guards to top of `fn vote()` before deploying |

## Transpile

```bash
# From repo root
xtract demo/dao_governance/src/DaoGovernance.sol \
        demo/dao_governance/src/DaoGovernance.rs
```

Verify zero TODO comments:

```bash
grep "// TODO" demo/dao_governance/src/DaoGovernance.rs | wc -l
# → 0
```

---

## Build

Requires the MultiversX Rust toolchain:

```bash
rustup target add wasm32-unknown-unknown
cargo install multiversx-sc-meta
```

Then from this directory:

```bash
sc-meta all build
```

This produces `output/dao-governance.wasm`.

---

## Deploy

```bash
export WALLET_PEM=./wallet.pem
npx ts-node deploy.ts
```

The script:
1. Re-transpiles the Solidity source
2. Builds the WASM (requires sc-meta on PATH)
3. Deploys to devnet and prints the contract address + tx hash
