# NftStaking — NFT Staking Demo

A time-locked NFT staking contract that demonstrates real-world
Solidity→MultiversX Rust transpilation with XTract, focusing on
struct field updates and timestamp-based reward accumulation.

## What the contract does

| Endpoint | Description |
|---|---|
| `stake(tokenId)` | Stake an NFT (payable). Records owner and staking timestamp in a `StakeInfo` struct. |
| `unstake(tokenId)` | Return the NFT after the lock period. Verifies ownership and timelock. |
| `claimRewards(tokenId)` | Mint reward ESDT proportional to time staked (`rate * elapsed / day`). |
| `getStakeInfo(tokenId)` | View — returns `(active, stakedAt)` for a given token. |
| `isStaked(tokenId)` | View — returns whether the token is currently staked. |
| `setRewardRate(newRate)` | Owner-only — update the per-day reward rate. |
| `setLockPeriod(newPeriod)` | Owner-only — update the lock duration in seconds. |

### Solidity patterns exercised

- **A5 struct-field-update** — `stakes[tokenId].owner = msg.sender` → load-mutate-store:
  ```rust
  let mut s = self.stakes(&token_id).get();
  s.owner = caller;
  self.stakes(&token_id).set(&s);
  ```
- **block.timestamp** — maps to `self.blockchain().get_block_timestamp()`
- **Single-key struct mapping** — `mapping(uint256 => StakeInfo)` → `SingleValueMapper<StakeInfo>`
- **payable function** — `stake()` maps to `#[payable("*")]` with `EsdtTokenPayment`
- **onlyOwner modifier** — `require!(self.blockchain().get_caller() == self.owner().get(), …)`
- **Events** — `Staked`, `Unstaked`, `RewardsClaimed` with indexed params

### MultiversX production notes

| Solidity | MultiversX |
|---|---|
| `tokenId` uint256 param | ESDT nonce from `self.call_value().single_esdt()` |
| NFT ownership implicit | Verified by the blockchain on ESDT payment |
| Reward `transfer` | `self.send().esdt_local_mint(…)` + `direct_esdt(…)` |
| `#[payable("EGLD")]` | Replace with `#[payable("*")]` for ESDT NFTs |

## Transpile

```bash
# From repo root
xtract demo/nft_staking/src/NftStaking.sol \
        demo/nft_staking/src/NftStaking.rs
```

Verify zero TODO comments:

```bash
grep "// TODO" demo/nft_staking/src/NftStaking.rs | wc -l
# → 0
```

---

## Build

Requires the MultiversX Rust toolchain:

```bash
rustup target add wasm32-unknown-unknown
cargo install multiversx-sc-meta
```

Then from this directory:

```bash
sc-meta all build
```

This produces `output/nft-staking.wasm`.

---

## Deploy

```bash
export WALLET_PEM=./wallet.pem
npx ts-node deploy.ts
```

The script:
1. Re-transpiles the Solidity source
2. Builds the WASM (requires sc-meta on PATH)
3. Deploys to devnet and prints the contract address + tx hash
